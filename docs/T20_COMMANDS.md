## 0. 关键前提与坑（高置信度领域知识）

1. **天正对话框 ≠ AutoCAD 原生对话框。** 天正轴网、门窗、楼梯等命令使用天正
   自有的对话框引擎（基于 ObjectARX 的 dialog），**`CMDDIA=0` 通常只对 AutoCAD
   原生命令（如 `-INSERT`、`PLOT`、`-LAYER`）生效**，对天正自有对话框命令多半
   **无效**。因此「CMDDIA=0 绕过」一列对天正命令大多为「否 / 待验证」。
2. **绕过对话框的真实路径**通常是：
   - 命令是否存在「命令行版」别名（部分天正命令支持连续命令行输入）；
   - 或先在对话框内用一次、天正会**记忆上次参数**，后续可在命令行直接确认；
   - 或通过 `(command ...)` 对天正暴露的 `c:` LISP 函数/反应器接口传参。
   以上三条均**待真机验证**。
3. 本项目铁律：所有封装走 **LISP 模板 + 参数注入**，不硬编码键击序列。
   因此即便对话框无法绕过，模板里也以 `(command "<cmd>" ...)` 形式占位，留待
   真机校正交互序列，而非在 Python 侧拼接 SendKeys。
4. 坐标单位默认 **毫米 (mm)**；本编目角度单位默认 **度**。

1. 核对每个命令的**真实命令行别名**（菜单 → 命令行回显的英文/拼音命令名）。
