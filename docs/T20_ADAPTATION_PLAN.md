# T20 天正建筑适配改造清单草案

## 1. 窗口与进程嗅探适配
* 原始实现仅寻找包含 `autocad` 且包含 `drawing` 标题的窗口，天正 T20 运行时窗口标题可能是 `天正建筑 V[XX]` 等中文字符串。
* **计划改造点**：拓展 `find_autocad_window` 的关键字列表，支持包含 "天正"、"TArch" 或者主进程可执行文件名称（如 `acad.exe` 等）的联合匹配。

## 2. LISP 执行底层重构
* 天正自带大量复杂的业务命令（如绘制墙体、插入门窗）。上游项目仅实现了基本 AutoLISP 图元创建。
* **计划改造点**：
  * **禁止直接拼接按键**（铁律）：对于天正命令操作，必须采用 LISP 内置的 `(command "xx")` 或者构建带参数注入的封装，避免直接发送界面字符串导致因为界面焦点不同步而产生混乱。
  * 构建一组新的 `mcp-cmd-t20-*` 的 LSP 派发器专门针对天正对象类型进行读取。

## 3. DXF 与自定义图元 (Proxy Entity)
* 天正使用的是自定义图元（TCH_WALL 等），上游 `ezdxf_backend.py` 无法直接读取并解析其三维物理属性，可能会当作 proxy objects 处理。
* **计划改造点**：
  * 在进行 MCP DXF 后端读取之前，可以通过 LISP 调用天正的 `T81_TExplode`（分解天正对象）打散存至临时文件。
  * 或直接扩展 LISP API 提取 T20 对象的内置属性（墙厚、门窗高度等）作为 JSON 回传给 MCP Client。

## 4. IPC 路径适配
* 默认在 `C:/temp` 创建，应允许根据 Windows 环境变量动态选择临时目录，防止由于 C 盘根目录写权限不足导致报错。

*(注意：当前仅为草拟清单，未实施任何代码修改)*
