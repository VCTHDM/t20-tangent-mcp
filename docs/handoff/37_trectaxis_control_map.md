## 4. 重点分析

### 4.a 底部宽 Edit (123,444,431,457) 附近有无 `键入` 类 Static?

**没有**。直线 tab 的 Edit 3606520 与 弧线 tab 的 Edit 2820554 位于 y=444-457 长条, 但周边不存在带 `键入`/`键入间距`/`键入值` 文本的 Static。
- 上一水平带 y≈194-212: 上开/下开/左进/右进 Static (远离, y 相差 230+ 像素)。
- 下一水平带 y≈476-494: 总开间: / 总进深: / 轴网夹角: (对应 3 个统计/求和字段, 非 Edit 标签)。
- 该 Edit 左侧 x<123 区域无任何 Static。

结论: 这个宽 Edit 是**无标签**的裸输入框, 语义 (键入轴间距值序列, 由回车逐值送入右侧 ListBox) 只能靠 **位置 + class + 上方激活 radio** 定位, 无法用 title 锚定。运行时定位建议: Edit + rect.y∈[440,460] + rect.width>=250 + 位于 SysTabControl32 后代。

### 4.b (396,464,425,493) / (429,464,458,493) 两个无标题 owner-draw Button 身份

两组 hwnd:
- 直线 tab: 1575216 (左) / 3280670 (右)
- 弧线 tab: 2494358 (左) / 2494306 (右)

依据:
1. rect 高宽均为 29×29, 位于 Modal 右下角 (Modal rect 右边界 x=469, 下边界 y=498; 两按钮下缘 y=493 距下边界 5px)。这是标准 **确定/取消** 图标按钮的贴角位置。
2. Modal 中不存在任何 title='确定'/'取消' 的 Button — 天正 T20 惯例是将 OK/Cancel 做成 owner-draw 图标 (style `BS_OWNERDRAW=0x0B`, 即末字节 `B` 的 `0x5000000B`)。
3. Windows/CAD 对话框通用约定: 左 = **确定** (OK, 默认动作), 右 = **取消** (Cancel)。
4. 两个 owner-draw 按钮成对出现于两个 tab, 与直线/弧线各配一套, 说明是与 tab 生命期同步的对话按钮 (即 OK/Cancel), 而非拾取型工具按钮 (拾取型 style 相同但会带 `<` 后缀 title, 见 §3.2 的 `共用轴线<` / `内弧半径<`)。

**结论**:
- `(396,464,425,493)` → **确定 (OK)**  · 直线 hwnd=1575216, 弧线 hwnd=2494358
- `(429,464,458,493)` → **取消 (Cancel)** · 直线 hwnd=3280670, 弧线 hwnd=2494306

对 Gate A ESC 恢复而言, 需要点击"取消"关闭时优先使用 **右侧** hwnd, 而 WM_COMMAND(IDCANCEL)/ESC 也应等价 (owner-draw 仍响应 IDOK/IDCANCEL 命令)。

### 4.c (438,439,458,458) 小按钮

hwnd: 直线 4263868 / 弧线 4589864。20×19, style=0x5000000B (owner-draw)。

位置线索:
- x 范围 438-458 与右侧 OK/Cancel 列 (396-458) 的**右半**对齐 (即在"取消"正上方)。
- y 范围 439-458 紧贴 ListBox `18091670`/`4460430` 下缘 (y=426/427) 与 底部宽 Edit `3606520`/`2820554` 上缘 (y=444) 之间, 但 y=439 略高于 Edit 顶 (y=444), 说明它挨在 **ListBox 右下角外侧** (ListBox rect 右边界 x=457/458)。
- 与拾取点按钮 (`共用轴线<` 左下角) 不同 rect, 且不带 title, 采用图标绘制。

**推断**: 位于 ListBox 右下外侧的 owner-draw 小图标按钮, 最可能为 **删除/清空当前列表项** (ListBox 编辑辅助), 或"从图中拾取"入列辅助。无 title 可确认, 语义待运行时点击验证 (Gate B 之前视作黑盒, 不点击)。

## 5. hwnd 会话性与运行时重发现

以上所有 hwnd (Modal 5374562, SysTabControl32 2032488, 3 个内层 #32770, 全部 63 个子控件) 均**仅在本次 `_TRECTAXIS` 会话内有效**。ESC 关闭模态或天正重启后, 所有 hwnd 都会失效。运行时定位必须按 **class + 锚点邻近 (rect 距离 / title Static / 父级 #32770 层级)** 重发现:

1. 先按 `class='#32770'` + Modal 顶层 title 空 + owner=天正主窗筛出 Modal (确认命中 TRectAxis 面板可再校验存在 `SysTabControl32` 后代)。
2. 在 Modal 内先定位 SysTabControl32 → 取其 `TCM_GETITEMCOUNT`/子 `#32770` → 用 visible=True 的内层 `#32770` 作为当前 tab 的容器。
3. 语义控件按下列锚点重发现 (示例):
   - 底部宽 Edit (键入区): `class='Edit'` + rect.y∈[440,460] + rect.width>=250, 且是当前 tab 容器下 y 最大的 Edit。
   - OK/Cancel: `class='Button'` + `style & 0xF == 0xB` (OWNERDRAW) + rect 位于 Modal 右下 20px 边距内, 按 x 排序取最左 (OK) / 最右 (Cancel)。
   - 上开/下开/左进/右进 radio: `class='Button'` + `style & 0xF == 9` (AUTORADIOBUTTON) + 每个 radio 用 `right==该 Static 的 left AND |Δy|<=2` 去匹配 Static title 之一。
   - ListBox: `class='ListBox'` + 位于当前 tab #32770 内部, 唯一 (直线) 或按 visible 择一 (弧线独立副本)。
   - 轴网夹角 Edit: `class='Edit'` + 位于 Static `轴网夹角:` 右侧 (rect.x > Static.right AND |Δy|<=15)。

注: 因同一 hwnd 在原始 Gate A 树里被 `[1]` (Modal 直属) 与 `[2]` (嵌套) 双重登记, 运行时枚举需按 hwnd 去重; 本文件的 63 项即去重结果。
