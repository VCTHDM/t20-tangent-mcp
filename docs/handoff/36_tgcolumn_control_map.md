## 4. 确定 / 取消 / OK / Cancel 按钮

**遍历全部 68 个 Button, 未找到 title 为 `确定` / `取消` / `OK` / `Cancel` 的按钮。**

→ **不存在**, 该面板是**非模态即时生效式**:
参数改动后无 "确定" 需按, 用户须在图形区拾取插入点/继续命令来落地实体;
取消由 `ESC` (顶层命令级) 完成, 而非对话框级 Cancel。
这与 Handoff 13/25 观察 (`OSMODE=0` + `CMDACTIVE=1` 持续等待鼠标输入) 一致。

| 图库 动作按钮 | 528126 | Button | `0x5000000B` | (179,481,248,500) | `Button title='标准构件库'`, y 与 `Static title='图库：'` 同行 |

style 位含义速查:
- `0x50000000` = `WS_CHILD | WS_VISIBLE`
- `0x50000081` = 上述 + `ES_LEFT | ES_AUTOHSCROLL` (标准单行 Edit)
- `0x50000262` / `0x50000263` = ComboBox `CBS_DROPDOWN(LIST)` + `WS_VSCROLL` + tab-stop 差异
- `0x5000000B` = Button `BS_OWNERDRAW` (自绘按钮, 天正常用)
- `0x58000xxx` = 附带 `WS_DISABLED` (0x08000000)

## 注意

**hwnd 是会话性的**: 上表所有 hwnd 均来自单次 launch (`modal=6686862`), 一旦对话框重建就会全部改变。
运行时**必须**按以下顺序重新发现:

1. 定位顶层 `#32770 owner_hwnd=<AutoCAD主窗口> title=''` 且 rect 宽≈175、高≈446 的模态子窗口;
2. 枚举其后代, 用 **class + 相邻 title 锚点** (Static/Button 的 title 文字) 结合 rect 坐标邻近关系匹配, 而非缓存 hwnd;
3. 尤其对柱高 Edit — 认准 "父容器是 `#32770 title='柱高'` 的唯一 Edit 子孙"; 对材料/转角 ComboBox — 认准 "与 `Static title='材料：'`/`'转角：'` y-重叠且在其右侧的 ComboBox"。
